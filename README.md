CS 340 Portfolio Reflection
Writing Maintainable, Readable, and Adaptable Programs

To ensure maintainability and readability, I designed my code using modular and reusable components. A key example is the CRUD Python module developed in Project One, which encapsulates all database interactions in a single location. By separating database logic from the dashboard interface in Project Two, the application became easier to debug, update, and extend. This approach allowed changes to database queries without impacting the dashboard layout or user interface logic. In the future, this CRUD module could be reused for other dashboards, analytics tools, or client-facing applications that require structured access to MongoDB data.

Problem-Solving Approach as a Computer Scientist

I approached this project by first analyzing the client requirements provided by Grazioso Salvare and translating them into technical specifications. I identified the data needed to support each rescue scenario, designed MongoDB queries to meet those requirements, and then built the dashboard incrementally. This approach differed from earlier coursework by emphasizing real client needs, data filtering accuracy, and user interaction rather than isolated technical tasks. In future projects, I would continue using this requirement-driven approach by prototyping database queries early and validating results before integrating them into an application.

The Role of Computer Scientists and Why It Matters

Computer scientists design systems that transform raw data into actionable information. In this project, my work enables Grazioso Salvare to quickly identify animals suited for specific rescue operations, reducing manual data review and improving decision-making speed. Applications like this help organizations operate more efficiently, reduce errors, and better serve their missions. This project demonstrates how software solutions directly support real-world outcomes by improving data accessibility and usability.
